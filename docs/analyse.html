    DISTANCE RULE

    統合判定は、形の差を window 長で公平にする

    単音では各点の差を現在の文脈幅で割ります。距離比が設定閾値以下なら、同じパターンとして扱います。

    各点di = clamp(|ai − bi| / value_width, 0, 1)
    部分列distance = √ Σ di2
    最終判定ratio = distance / √window ≤ threshold
